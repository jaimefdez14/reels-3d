Conectar con GitHub

El panel se ve sin conexión. Para decidir desde aquí (aprobar voz, publicar, pedir cambios), pega un token de GitHub. Se guarda solo en este navegador.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Repository access: Only select repositories → reels-3d.
  3. Permissions: Issues y Actions en «Read and write»; Contents en «Read-only».
  4. Genera el token y pégalo aquí.
