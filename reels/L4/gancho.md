# Revisor de gancho (10-11)
NO PASA: «dejándolo» sin antecedente; «el tercero es el que mejor funciona» calco de *works best*. Su versión; la frase del tercero se ajusta para cerrar la promesa.
- 0: «Llevas tres días / *dejándolo para mañana.*» → «Eso que llevas tres días dejando para mañana, / *lo vas a hacer hoy.*»
- 1: «Cinco trucos para hacerlo hoy. / *Y el tercero es el que mejor funciona.*» → «Cinco trucos. / *Y con el tercero ya no hay excusa.*»
- 10: «Y por eso funciona tan bien: / acabas un trozo / *y te pones con el siguiente sin pensarlo.*» → «Por eso con este no hay excusa: / acabas un trozo / *y te pones con el siguiente sin pensarlo.*»

# Revisor de gancho, ronda 2 (10-11)
PASA por poco. Retoque opcional aplicado: menos tono de anuncio; la frase del tercero cierra la promesa.
- 0: «Eso que llevas tres días dejando para mañana, / *lo vas a hacer hoy.*» → «Eso que llevas tres días dejando para mañana: / *hoy lo haces.*»
- 1: «Cinco trucos. / *Y con el tercero ya no hay excusa.*» → «Cinco trucos, / *y el tercero te quita la excusa.*»
- 10: «Por eso con este no hay excusa: / acabas un trozo / *y te pones con el siguiente sin pensarlo.*» → «Por eso te quita la excusa: / acabas un trozo / *y te pones con el siguiente sin pensarlo.*»
